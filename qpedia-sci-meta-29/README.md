## چه چیزی هرگز تغییر نمی‌کند

- **اسلاگ (`post_name`) هیچ صفحه‌ای** — در هر به‌روزرسانی، اسلاگ فعلی صریحاً عوض خودش بازنویسی
  می‌شود؛ لینک‌های داخلی سایت سالم می‌مانند.
- محتوای متن بدنه، تاریخ انتشار، وضعیت انتشار، دسته، نویسنده، تصویر شاخص.
- چکیده یا متای پرشدهٔ موجود (هرگز بازنویسی نمی‌شود — بخش ۲۱.۳).
- هیچ برگهٔ جدیدی ساخته نمی‌شود؛ اسلاگ ناموجود فقط لاگ می‌شود.

## محافظ‌های ایمنی

1. عنوان فقط وقتی عوض می‌شود که عنوان فعلی دقیقاً برابر مقدار «قدیم» ثبت‌شده در داده باشد؛
   غیر این ← هشدار و دست‌نزدیدن.
2. چکیده فقط وقتی نوشته می‌شود که خالی باشد.
3. متا فقط وقتی نوشته می‌شود که **هر دو** کلید خالی باشند.
4. نام انگلیسی فقط اگر دقیقاً مقدار غلط فعلی (`albert-einstein`) باشد.
5. حذف `schrodingerr` **نرم** است (سطل زباله؛ قابل بازگردانی). هیچ لینک ورودی‌ای به این
   اسلاگ وجود ندارد (بررسی شد روی خروجی زندهٔ وردپرس).

## نصب و اجرا

1. پیشخوان وردپرس ← افزونه‌ها ← افزودن ← بارگذاری افزونه ← `qpedia-sci-meta-29.zip`
2. فعال‌سازی.
3. ابزارها ← **QPedia Sci Meta 29**
4. اول دکمهٔ **«پیش‌نمایش بدون تغییر»** — فهرست کامل تغییرات را ببینید.
5. اگر لاگ مورد تأیید بود، **«اجرای نهایی»**.

## نکته‌ها

- «تاریخ آخرین ویرایش» صفحاتِ ویرایش‌شده به‌روز می‌شود (رفتار طبیعی وردپرس)؛ تاریخ انتشار اصلی دست نمی‌خورد.
- **افزونه را فعال نگه دارید** تا ریدایرکت ۳۰۱ (`/scientists/schrodingerr/` ← `/scientists/erwin-schrodinger/`) کار کند.
  اگر خواستید غیرفعالش کنید، قاعدهٔ ریدایرکت باید به قالب منتقل شود (درخواست کنید تا جداگانه انجام شود).
- چکیدهٔ تازهٔ ۱۱ صفحه به‌طور خودکار از سوی تابع `qpedia_auto_seo_meta_tags` قالب به
  تگ `<meta name="description">` و OpenGraph همان صفحه‌ها هم می‌رسد.
