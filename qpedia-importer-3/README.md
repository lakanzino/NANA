# QPedia Importer 3

افزونهٔ ایمپورت مقالات کیوپدیا — نسل سوم.

## چه فرقی با نسل ۱ و ۲ دارد؟
| | نسل ۱/۲ | **نسل ۳** |
|---|---|---|
| منبع داده | payload فشردهٔ base64 داخل PHP | فایل ساده و ویرایش‌پذیر `data/articles.json` |
| افزودن مقاله | نیاز به اجرای اسکریپت پایتون و ری‌بیلد | فقط یک آبجکت به JSON اضافه کنید |
| دسته‌بندی | فقط زیردستهٔ برگ | **برگ + همهٔ والدها به‌صورت خودکار** |
| به‌روزرسانی مقالهٔ موجود | ندارد | دارد (تیک‌دار) |
| پیش‌نمایش قبل از اجرا | ندارد | جدول کامل پیش‌نمایش |
| ایمپورت به‌صورت پیش‌نویس | ندارد | دارد |

## نصب
۱. پوشهٔ `qpedia-importer-3` را zip کنید.
۲. پیشخوان → افزونه‌ها → افزودن → بارگذاری افزونه.
۳. فعال‌سازی → منوی **ابزارها → QPedia Importer 3**.

## ساختار `data/articles.json`
```json
{
  "articles": [
    {
      "slug": "quantum-gravity",
      "title": "گرانش کوانتومی چیست؟",
      "excerpt": "دو ستون فیزیک مدرن با هم جور درنمی‌آیند. این مقاله ... را بررسی می‌کند.",
      "category": "interpretations",
      "html": "<p>...</p>",
      "meta": { "reading_time": "9" }
    }
  ]
}
```

| فیلد | الزامی | توضیح |
|---|:---:|---|
| `slug` | ✅ | اسلاگ انگلیسی؛ کلید یکتا برای تشخیص تکراری |
| `title` | ✅ | تیتر سئو فارسی |
| `excerpt` | ➖ | چکیدهٔ ۲ جمله‌ای (فیلد `post_excerpt`) |
| `category` | ➖ | اسلاگ **زیردستهٔ برگ**؛ والدها خودکار اضافه می‌شوند |
| `html` | ➖ | بدنهٔ HTML خالص مقاله |
| `meta` | ➖ | جفت‌های کلید/مقدار برای `update_post_meta` |
| `author_id` | ➖ | شناسهٔ نویسنده |

## نکات
* HTML خام دست‌نخورده ذخیره می‌شود (`kses` موقتاً غیرفعال) — فقط برای ادمین.
* اجرای دوباره امن است: با تیک به‌روزرسانی، مقالهٔ موجود آپدیت می‌شود نه تکراری.
* دسته‌ها اگر نبودند خودکار ساخته می‌شوند (اول والدها بعد فرزندان).
