# چارچوب پیش‌نیاز نوشتن هر فصل کتاب الف

قبل از نوشتن هر فصل، نویسنده این صفحه را می‌خواند. بدون این قفل‌ها، متن وارد qbook نمی‌شود.

سند حاکم: **qbook ۱٫۱٫۰ به بعد.** تعارض = qbook مقدم است.

## ۱) هویت

کتاب آموزش تفکر علمی است *از طریق* کوانتوم.  
نه معرفی عجایب + یک فصل شبه‌علم در انتها.

موضع روی صفحهٔ حقوق:  
فیزیک کوانتوم علم است، عجیب است، و هنوز تمام حقیقتش را نمی‌دانیم. عجیب‌بودن مجوز خرافه نیست.

## ۲) زنجیرهٔ اجباری (به همین ترتیب در متن)

شگفتی → آزمایش → مفهوم → تشبیه → محدودیت تشبیه → شواهد → سوءبرداشت → تفکر انتقادی

ممنوع: شگفتی → عجیب بودن → نتیجه‌گیری فلسفی/ماورایی.

| حلقه | حداقل در فصل |
|---|---|
| شگفتی | صحنهٔ ملموس + یک بار «صبر کن، چی؟!» |
| آزمایش | چه دیده می‌شود، نه شعار |
| مفهوم | یک ایده؛ ورم فصل بعد نیاید |
| تشبیه | ایرانی، قبل از اصطلاح دشوار |
| محدودیت تشبیه | صریح بگو استعاره کجا می‌شکند |
| شواهد | نام + مأخذ قابل‌ردیابی |
| سوءبرداشت | کادر سوءتفاهم رایج + تصحیح |
| تفکر انتقادی | مرز علم و قصه + برای فکر کردن |

## ۳) خط قرمز حقیقت

- نقل‌قول بدون سند — هرگز. گیومه فقط اگر متن اصلی در منبع قفل‌شده دیده شده باشد.
- تاریخ بدون مأخذ معتبر — هرگز. اگر مأخذ نداری: «آغاز قرن بیستم» به‌جای سال.
- عدد ثابت‌ها فقط با NIST/CODATA یا منبع هم‌تراز؛ وگرنه عدد نیاور.
- ویکی‌پدیا به‌تنهایی کافی نیست.
- کیوپدیا مادهٔ خام است نه مأخذ نهایی تاریخ و نقل‌قول.

## ۴) لحن و حجم

- ۱۴۰۰ تا ۱۸۰۰ کلمهٔ فارسی (بدون فهرست منابع).
- دوم‌شخص، معلم دقیق، جملهٔ کوتاه، نیم‌فاصله.
- حداکثر یک اصطلاح معلمانه («ببینید» / «بریم سر اصل داستان»).
- عنوان و زیرعنوان فصل قفل است.

## ۵) ترتیب کار نویسنده

1. خواندن این چارچوب.
2. خواندن «پیش‌نیاز قفل‌شده» همان فصل (حقایق مجاز).
3. خواندن مادهٔ خام کیوپدیا + حداقل دو مأخذ جهانی همان فهرست.
4. نوشتن روی زنجیره.
5. خودآزمایی چک‌لیست انتهای پرامپت فصل.
6. تحویل برای فیلتر qbook. ثبت فقط بعد از تأیید.

اگر حقیقتی در پیش‌نیاز فصل نیست، در متن نیاید — حتی اگر قصه را قشنگ‌تر کند.
