## وضعیت

متن فصل‌ها پیش‌نویس روایی است نه نسخهٔ نهایی چاپ. کادرهای «سوءتفاهم / مرز علم و قصه / برای فکر کردن» در همهٔ فصل‌ها آمده‌اند.

قوانین نشر ایران و تطبیق اداری — مرحلهٔ بعد، طبق خواستهٔ این دور.
