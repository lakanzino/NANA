# QPedia Article Updater v2026.09.13c

افزونهٔ وردپرس برای به‌روزرسانی تک‌دکمه‌ای مقالات `quantum_article`.

## تغییرات نسخه c
- تمام فایل‌های webp دیاگرام‌ها در پوشهٔ `assets/images/` داخل افزونه باندل شده‌اند؛ ایمپورتر اول از روی دیسک می‌خواند و **نیازی به اتصال اینترنت بین‌الملل** نیست.
- در صورت نیاز به دانلود از GitHub Pages، هر تصویر تا ۳ بار با تایم‌اوت افزایش‌یافته (۲۰s, ۳۵s, ۵۰s) تلاش می‌شود.
- فیلد `featured_image` خالی باشد تصویر شاخص فعلی سایت دست نمی‌خورد.
- نقشهٔ رسمی اسلاگ‌ها در `slug-map.json` (استخراج شده از فهرست به‌روز سایت) داخل افزونه قرار داده شد تا دیگر هیچ گمانه‌زنی روی اسلاگ‌ها انجام نشود.

## نحوهٔ کار
1. فایل زیپ را از طریق «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید.
2. در پیشخوان از منوی «مقالات کوانتوم ← 📥 به‌روزرسانی مقاله» وارد صفحه شوید.
3. اول **Dry-Run** بزنید، بعد **Apply**.

## ساختار پوشه
- `payloads/*.json` — محتوای هر مقاله به همراه URL تصاویر درون‌متن.
- `assets/images/*.webp` — همان تصاویر، به‌صورت محلی، برای sideload بدون اینترنت.
- `slug-map.json` — اسلاگ↔عنوان مقالات زندهٔ سایت.
