# کوانتوم پدیا — PWA

اپلیکیشن پیش‌رونده وب (PWA) برای دانشنامه فیزیک کوانتوم به زبان ساده.
محتوا از طریق REST API وردپرسِ `https://qpedia.ir` دریافت می‌شود.

## ساختار پوشه

```
pwa/
├── index.html          # شِلِ اصلی اپ (HTML، RTL، فارسی)
├── styles.css          # استایل‌ها و طراحی موبایل‌محور
├── app.js              # منطق اپ، دریافت داده، رندر صفحه‌ها
├── sw.js               # Service Worker (حافظهٔ نهان و کار آفلاین)
├── manifest.json       # مانیفست نصب روی صفحهٔ اصلی
└── icons/
    ├── icon-192.png    # آیکون ۱۹۲×۱۹۲
    └── icon-512.png    # آیکون ۵۱۲×۵۱۲
```

## منبع داده

`app.js` در خط اول آدرس API را دارد:

```js
const API = 'https://qpedia.ir/wp-json/wp/v2';
```

 سه اندپوینت استفاده می‌شود:

| اندپوینت              | توضیح                    |
| --------------------- | ------------------------ |
| `quantum_article`     | مقالات (با `_embed`)     |
| `quantum_scientist`   | دانشمندان                |
| `quantum_category`    | دسته‌بندی موضوعات        |

داده‌ها به مدت ۳۰ دقیقه در `localStorage` کش می‌شوند تا اپ سریع و نیمه‌آفلاین باشد.

## استراتژی کش (sw.js)

- **App Shell** → Cache-first (فایل‌های اصلی اپ)
- **درخواست‌های `/wp-json/`** → Network-first با فالبک به کش
- نسخهٔ فعلی کش: `qpedia-pwa-v2`

> هنگام تغییر فایل‌ها، مقدار `CACHE_NAME` را در `sw.js` افزایش بدهید
> تا کش قدیمی کاربران پاک شود.

## اجرای محلی

Service Worker فقط روی `https` یا `http://localhost` کار می‌کند.
برای تست محلی:

```bash
cd pwa
python3 -m http.server 8000
```

سپس مرورگر را روی `http://localhost:8000` باز کنید.

## استقرار (Deploy)

کل پوشهٔ `pwa` را روی هر هاست استاتیک (یا زیرپوشه‌ای مثل
`https://qpedia.ir/pwa/`) آپلود کنید. نکته‌ها:

- مسیرها همه **نسبی** هستند؛ پوشه را می‌توان در هر زیرمسیری قرار داد.
- فایل‌های پوشه باید با `Content-Type` درست سرو شوند
  (`.js` → `application/javascript`، `manifest.json` → `application/manifest+json`).
- برای نصب کامل PWA، سایت باید روی **HTTPS** باشد.
