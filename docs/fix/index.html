📦 دانلود بسته کامل اصلاحات

یک فایل zip شامل همهٔ فایل‌های اصلاح‌شده. این را دانلود کن و از طریق سی‌پنل یا FTP در مسیر قالب فرزند جایگزین کن.

⬇️ دانلود qpedia-child-perf-fix.zip
پس از آپلود و جایگزینی فایل‌ها، وارد پیشخوان وردپرس شو و از منوی LiteSpeed Cache → Purge All کش سایت را خالی کن.

📄 فایل‌های تغییرکرده (تکی)

اگر نمی‌خوای zip آپلود کنی، هر فایل را تکی دانلود یا محتوایش را کپی کن:

🛠 راهنمای نصب در سی‌پنل

  • وارد File Manager سی‌پنل شو.
  • به مسیر public_html/wp-content/themes/quantum-pedia-child/ برو.
  • سه فایل زیر را آپلود و جایگزین فایل‌های موجود کن:
    functions.php
    style.css
    assets/css/qpedia-brand.css
  • وارد پیشخوان وردپرس شده، LiteSpeed Cache → Purge All را بزن (همچنین اگر گزینه Guest Mode فعال است روی 「Empty Entire Cache」 هم بزن).
  • مهم: مرورگر خود را کاملاً ببند یا یک پنجره Incognito/ناشناس باز کن (تا کش قدیمی HTML مرورگر مزاحم نشود).
  • سایت را باز کن و با PageSpeed تست بگیر.
