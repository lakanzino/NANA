# اصلاح رنگ اصطلاح واژه‌نامه

## مشکل

هایلایت سبزآبی درست کار می‌کرد، اما **رنگ متن خودِ اصطلاح** هم
سبزآبی روشن شده بود و روی هایلایت هم‌رنگ گم می‌شد.

## علت

در `quantum-glossary.css` سه جا رنگ متن دست‌کاری می‌شد:

| حالت | رنگ | وضعیت |
|---|---|---|
| روشن | `#0F766E` سبزآبی تیره | قابل قبول |
| هاور | `#0B5C57` | خوب |
| **حالت تیرهٔ سیستم** | **`#5EEAD4`** | 🔴 **مقصر** |

بلوک `@media(prefers-color-scheme:dark)` رنگ متن را به سبزآبی روشن
عوض می‌کرد — تقریباً همان رنگ هایلایت. این بلوک وقتی فعال می‌شود که
**سیستم یا مرورگر کاربر** روی حالت تیره باشد، حتی اگر خودِ سایت
روشن باشد. برای همین بعضی کاربران مشکل را می‌دیدند و بعضی نه.

نسخهٔ `ORIGINAL` هم رنگ آبی `#2563EB` داشت، که نشان می‌دهد ممکن است
روی سایت نسخهٔ دیگری فعال باشد.

## راه‌حل

**رنگ متن اصطلاح هرگز تغییر نمی‌کند.**

`color:inherit` یعنی اصطلاح دقیقاً همان رنگ متن پاراگراف را می‌گیرد.
پس در متن مشکی، مشکی می‌ماند؛ و اگر روزی سایت حالت تیره داشت، خودکار
روشن می‌شود — بدون آنکه با هایلایت قاطی شود.

تمایز اصطلاح از دو راه دیگر حفظ می‌شود: **هایلایت پس‌زمینه** و
**بولد بودن**.

## دو فایل

### ۱. `quantum-glossary.css` — جایگزین کامل
فایل اصلی را با این عوض کنید. مسیر معمولش:

    wp-content/themes/quantum-pedia-child/assets/css/quantum-glossary.css

### ۲. `override-only.css` — راه سریع‌تر
اگر نمی‌خواهید فایل اصلی را دست بزنید، محتوای این فایل را کپی کنید
در:

**نمایش ← سفارشی‌سازی ← افزودنی CSS**

با `!important` نوشته شده تا بر هر استایل دیگری غلبه کند.

## اگر مشکی ثابت می‌خواهید

در انتهای `override-only.css` یک بلوک توضیح‌دار هست. کافی است
علامت توضیح را بردارید:

```css
.quantum-glossary-term,
.quantum-glossary-term:hover,
.quantum-glossary-term.active{ color:#111827 !important; }
```

## پس از اعمال

**Purge All در LiteSpeed** را بزنید و صفحه را با `Ctrl+Shift+R`
تازه کنید.

اگر باز هم تغییری ندیدید، احتمالاً LiteSpeed فایل‌های CSS را ترکیب
و کش کرده — در آن صورت:
Page Optimization ← CSS Settings ← موقتاً `CSS Combine` را خاموش
کنید، تست کنید، بعد دوباره روشن کنید.
