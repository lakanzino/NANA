# راهنمای نصب — بازطراحی صفحهٔ نخست

چهار فایل عوض می‌شود. **دو تا جایگزینی کامل، یکی فایل جدید، یکی ویرایش کوچک.**

قبل از هر کاری: از هر سه فایل قدیمی یک کپی پشتیبان بگیرید.

این یک نماد اتم است: سه مدار بیضی چرخیده و یک هسته در وسط. **۵۸۲ بایت** و چون داخل خود صفحه است، هیچ درخواست شبکه‌ای اضافه نمی‌کند.

**تغییر دوم در همین فایل:** متن زیر عنوان کوتاه شد.

```

جایش نشست:

```

## گام ۴ — یک ویرایش کوچک در `functions.php`

**مسیر روی سرور:**
```
wp-content/themes/quantum-pedia-child/functions.php
```

اینجا **کل فایل را عوض نکنید** اگر نمی‌خواهید. فقط یک تکه را پیدا و جایگزین کنید.

**دنبال این تکه بگردید** (حدود خط ۴۵۶):
```php
function qpedia_child_enqueue_styles() {
    $ver = '1.0.3';
    if ( file_exists( get_stylesheet_directory() . '/assets/css/qpedia-layouts.css' ) ) {
        wp_enqueue_style( 'qpedia-layouts', get_stylesheet_directory_uri() . '/assets/css/qpedia-layouts.css', array(), $ver );
    }
}
```

**و کل آن را با این جایگزین کنید:**
```php
function qpedia_child_enqueue_styles() {
    $ver = '1.0.4';
    if ( file_exists( get_stylesheet_directory() . '/assets/css/qpedia-layouts.css' ) ) {
        wp_enqueue_style( 'qpedia-layouts', get_stylesheet_directory_uri() . '/assets/css/qpedia-layouts.css', array(), $ver );
    }

    // استایل تازهٔ صفحهٔ نخست — فقط روی صفحهٔ اول بارگذاری می‌شود.
    if ( is_front_page() && file_exists( get_stylesheet_directory() . '/assets/css/qpedia-front-v2.css' ) ) {
        wp_enqueue_style(
            'qpedia-front-v2',
            get_stylesheet_directory_uri() . '/assets/css/qpedia-front-v2.css',
            array( 'qpedia-layouts' ),
            $ver
        );
    }
}
```

**دو نکته:**
- عدد `1.0.3` به `1.0.4` تغییر کرد. این باعث می‌شود مرورگر کاربران CSS تازه را دانلود کند و نسخهٔ کش‌شده را نشان ندهد.
- شرط `is_front_page()` یعنی این CSS **فقط روی صفحهٔ اول** بارگذاری می‌شود. صفحات مقاله سبک‌تر می‌مانند.

اگر ترجیح می‌دهید کل فایل را عوض کنید، نسخهٔ آماده اینجاست:
`https://github.com/lakanzino/NANA/raw/arena/01a07278-nana/theme-fix-2/functions.php`

## تغییر مقاله‌های پیشنهادی

بخش «از این‌ها شروع کن» شش مقاله را دستی معرفی می‌کند. برای عوض کردنشان، در `front-page.php` دنبال این بخش بگردید:

```php
$qp_featured_slugs = array(
	array(
		'slug' => 'schrodinger-cat',
		'hook' => 'گربه‌ای که نه زنده بود نه مرده — و چرا این ماجرا اصلاً دربارهٔ گربه نیست.',
		'tag'  => 'معروف‌ترین',
	),
	...
);
```

هر ورودی سه بخش دارد:
- `slug` — اسلاگ مقاله (همان چیزی که در آدرس می‌آید)
- `hook` — یک جملهٔ قلاب که کاربر را کنجکاو کند
- `tag` — برچسب کوچک بالای کارت

**کارت اول عرض دو ستون می‌گیرد**، پس جذاب‌ترین مقاله را اول بگذارید.

اگر اسلاگی را اشتباه بنویسید، آن کارت فقط نمایش داده نمی‌شود و سایت خراب نمی‌شود.

## اگر کار نکرد

**اگر ظاهر عوض نشد:**
۱. مطمئن شوید فایل `qpedia-front-v2.css` واقعاً در مسیر `assets/css/` آپلود شده.
۲. آدرس زیر را مستقیم در مرورگر باز کنید — باید متن CSS را ببینید:
   `https://qpedia.ir/wp-content/themes/quantum-pedia-child/assets/css/qpedia-front-v2.css`
   اگر خطای ۴۰۴ داد، فایل در جای درست نیست.
۳. اگر فایل باز شد ولی سایت عوض نشده: **LiteSpeed ← Page Optimization ← CSS Settings** را موقتاً خاموش کنید و دوباره تست کنید.

**اگر سایت سفید شد:** یعنی در `functions.php` خطای تایپی رخ داده. فایل پشتیبان را برگردانید و دوباره با دقت کپی کنید.

**برای برگرداندن همه‌چیز:** سه فایل پشتیبان را برگردانید و `qpedia-front-v2.css` را حذف کنید.
