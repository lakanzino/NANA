# راهنمای نصب — صفحهٔ نخست (نسخهٔ ۶)

اگر صفحه فقط متن CSS شد، `front-page.php` را با فایل CSS عوض کرده‌اید. همان را برگردانید.

فایل PHP با `<?php` شروع می‌شود. CSS با `{` و `display` است. آن‌ها را جابه‌جا نکنید.

`qpedia-brand.css` را دیگر روی سرور نگذارید و داخل هیچ فایل PHP نچسبانید. استایل داخل `functions.php` است.

---

## اگر صفحه سفید یا پر از کد CSS است — همین الان

فقط این دو فایل را **کامل جایگزین** کنید (دانلود → در File Manager روی فایل موجود Upload / Overwrite):

1. `front-page.php` ← باید با `<?php` شروع شود  
   https://github.com/lakanzino/NANA/raw/arena/01a07c22-nana/theme-fix-2/front-page.php  
   مسیر: `wp-content/themes/quantum-pedia-child/front-page.php`

2. `header.php` ← باید با `<?php` شروع شود  
   https://github.com/lakanzino/NANA/raw/arena/01a07c22-nana/theme-fix-2/header.php  
   مسیر: `wp-content/themes/quantum-pedia-child/header.php`

3. `functions.php`  
   https://github.com/lakanzino/NANA/raw/arena/01a07c22-nana/theme-fix-2/functions.php  
   مسیر: `wp-content/themes/quantum-pedia-child/functions.php`

بعد LiteSpeed ← Toolbox ← **Purge All**

اگر در File Manager فایل `front-page.php` را باز کردید و `qp-global-header` یا `display:flex` دیدید، همان فایل غلط است. Overlay کنید.
