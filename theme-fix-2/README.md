# بازطراحی صفحهٔ نخست QPedia — نسخهٔ ۲

## فایل‌ها

| فایل | کار |
|---|---|
| `header.php` | لوگوی SVG جای تصویر PNG + تگ‌لاین کوتاه‌تر |
| `front-page.php` | ساختار جدید صفحهٔ اول |
| `qpedia-front-v2.css` | استایل بخش‌های تازه (فایل جدید) |
| `functions.php` | فقط تابع بارگذاری CSS عوض شده |
| `راهنمای-نصب-صفحه-نخست.md` | **از اینجا شروع کنید** |
| `*.ORIGINAL.php` | نسخه‌های پشتیبان قبل از تغییر |

## خلاصهٔ تغییرات

1. **لوگو** → SVG درون‌خطی، ۵۸۲ بایت، صفر درخواست شبکه.
2. **متن معرفی** → کوتاه و معنادار.
3. **«از کجا شروع کنم؟»** → حذف شد؛ جایش «از این‌ها شروع کن» با شش مقالهٔ واقعی نشست.
4. **«آخرین مقاله‌ها»** → دکمه‌اش از «مرور دسته‌ها» به «همهٔ مقاله‌ها» تغییر کرد.
5. **دانشمندان** → از دو ردیف سه‌ستونه به یک ردیف اسلایدری، با بارگذاری تنبل تصاویر.

## سبکی

- بدون جاوااسکریپت (اسلایدر با اسکرول بومی مرورگر).
- بدون تصویر و فونت تازه.
- CSS فقط روی صفحهٔ اول بارگذاری می‌شود.
- تصاویر دانشمندان: سه تای اول `eager`، بقیه `lazy`؛ اندازه از `medium_large` به `medium` کاهش یافت.
