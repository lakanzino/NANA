## تغییرات ظاهری

1. **هدر** → نشان متنی `QUANTUM PEDIA` جای تصویر PNG.
2. **فوتر** → لوگوی اختصاصی مالک، بزرگ‌تر (۶۴px) + نشان متنی + `loading="lazy"`.
3. **متن معرفی** → کوتاه و معنادار.
4. **«از کجا شروع کنم؟»** → حذف؛ جایش «از این‌ها شروع کن» با شش مقالهٔ واقعی.
5. **آخرین مقاله‌ها** → آمد بالاتر، بدون تصویر شاخص، با نوار گرادیان سبز-آبی روی گوشه.
6. **جست‌وجو** → منتقل شد بین مقالات تازه و دسته‌بندی.
7. **شمارنده‌ها** → پایین‌تر رفتند، با انیمیشن شمارش هنگام اسکرول.
8. **دانشمندان** → یک ردیف اسلایدری به‌جای دو ردیف سه‌ستونه.

- شمارنده: **۲.۲ کیلوبایت** جاوااسکریپت خالص، بدون کتابخانه، با `defer`.

- احترام به `prefers-reduced-motion`.
